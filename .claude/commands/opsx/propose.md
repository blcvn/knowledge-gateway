Create a new OpenSpec change under `openspec/changes/` and generate the proposal, design, and tasks artifacts for it.

Use this when the user wants to describe a new feature or change and get a ready-to-implement OpenSpec package.

Keep the change scoped to the request, read existing OpenSpec context first, and prefer the repo's current schema and style.
