# Deprecated Zep Memory Service

> **⚠️ DEPRECATION NOTICE ⚠️**
>
> The standalone `zep-memory` service has been deprecated and its functionality has been merged into the unified `zep-core` service to eliminate cross-service gRPC latency overhead.
>
> Please refer to `services/zep-core` for the active codebase.

This module is retained strictly for historical compatibility and audit trail.
